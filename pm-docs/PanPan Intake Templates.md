# **Standard Operating Procedure: Demand Intake**

**Process Owner:** AI Project Manager  
**Customer:** Panda (VOC)

## **🛑 Gate 1 Policy (Intake & Triage)**

The AI Project Manager MUST NOT proceed to Architecture or Execution until Panda's raw request is structured into one of the following templates and formally approved by Panda.

### **Template A: Feature Request**

*Use this when introducing net-new functionality or changing existing behavior.*  
**1\. User Story**  
As a User Persona/Panda, I want Specific Feature/Action so that Specific Benefit/Value.  
**2\. Acceptance Criteria (AC)**  
*(Must be measurable true/false statements)*

> * AC 1: Condition that must be met  
> * AC 2: Condition that must be met  
> * AC 3: Condition that must be met

**3\. Technical Constraints & Context**

> * **Affected Files:** (e.g., content.js, popupui.html)  
> * **Design/UI Impact:** (e.g., Requires a new toggle in the settings menu)

### **Template B: Bug Report**

*Use this when existing functionality deviates from the expected baseline.*  
**1\. Defect Description**  
Short, concise summary of what is broken  
**2\. Steps to Reproduce**

> 1. Navigate to: https://odr.appstate.edu/  
> 2. Perform action: Exact clicks or keyboard inputs  
> 3. Observe: What breaks

**3\. Baseline vs. Defect**

> * **Expected Result: **What should happen  
> * **Actual Result: **What actually happens

**4\. Environmental & DOM Data**

> * **Target Site:** (e.g., kagane.to/manga/xyz)  
> * **DOM Snippet / CSS Class:** (If the site structure changed, paste the new HTML snippet here)
